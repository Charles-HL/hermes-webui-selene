# Maintainer knowledge index

Start with [Status](STATUS.md). This small Markdown wiki carries durable project context across sessions; Git remains the code history. Pages are public, reviewed summaries rather than raw conversations.

- [Status and next action](STATUS.md): dated release/PR snapshot and pending work.
- [Decisions](DECISIONS.md): product boundaries and native behavior constraints.
- [Workflow](WORKFLOW.md): edit, validate, synchronize the gallery and release.
- [History](HISTORY.md): milestone chronology, evidence and limitations.
- [Sources](SOURCES.md): rationale for the agent/memory setup.
- [Validation](../VALIDATION.md): detailed visual and behavior evidence.

Private local context is in the ignored `.local/RESUME.md`, when available. A public clone cannot recover that file; maintain a separate private backup. Keep public/private summaries independently useful and never promote private content automatically.

Each update should state what was observed, when and from which commit or source. Refresh live PR/install state before acting; do not mistake historical passing tests for checks on a new head. Add a page only when an existing page cannot hold the topic clearly.
