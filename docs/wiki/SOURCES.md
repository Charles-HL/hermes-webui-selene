# Sources and maintenance rationale

Researched 2026-10-07. These are primary sources, not instructions to install tools or execute their examples.

- [AGENTS.md](https://agents.md/): portable repository instructions, real setup/check commands and project boundaries. Applied as a short entry point linking detailed pages.
- [Anthropic: effective harnesses for long-running agents, 2025-11-26](https://www.anthropic.com/engineering/effective-harnesses-for-long-running-agents): progress artifacts plus Git history help a fresh session resume. Applied through a current status snapshot, curated history and explicit next action.
- [Anthropic: harness design for long-running application development, 2026-03-24](https://www.anthropic.com/engineering/harness-design-long-running-apps): structured handoffs and complexity added only when justified. Applied without adding an autonomous agent service or database.
- [Karpathy: LLM Wiki, 2026-04-04](https://gist.github.com/karpathy/442a6bf555914893e9891c11519de94f): persistent linked knowledge distilled from sources. This is an idea pattern, not a required standard. Applied as a small reviewed Markdown wiki; raw private sources stay private.
- [Git ignore documentation](https://git-scm.com/docs/gitignore): ignored paths are untracked files; ignore rules do not affect files already tracked. Applied through ignore rules plus staged-content review and explicit release allowlisting.

Public notes contain verified summaries and links. Raw session exports and installation details belong in private storage. Review stale assertions and contradictions during each handoff. Neither a memory service nor this wiki replaces checking code, CI or the installed build.
