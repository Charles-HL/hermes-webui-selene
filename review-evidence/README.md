# Selene 1.1.3 review evidence

These are local native-template/CSS fixtures with synthetic history and context/quota data, and native markup from the benign demo conversation. They validate presentation, not backend services. The large-history fixture uses core `_sessionVirtualWindow` with a measured 38 px fixture row height, 200 synthetic conversations, native `sessionList` scroll position and spacer rendering; it is not the full core session renderer. Main `screenshots/` remain actual installed chat captures.

This folder is excluded from the release ZIP and the gallery entry. Round-1 captures are retained separately for historical review only.
